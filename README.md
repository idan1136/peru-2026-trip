# פרו 2026 - מסלול טיול 🇵🇪

אפליקציית ווב (PWA) עם מסלול הטיול המלא לפרו 2026 - 24 ימים, כולל לינה, תחבורה, אטרקציות ואזהרות גובה. עובדת **אופליין** לגמרי לאחר הפעלה ראשונה, וניתן להתקין אותה כאפליקציה על מסך הבית באייפון.

## התקנה על האייפון

1. פתחו את הקישור של האתר (GitHub Pages) ב-**Safari** (חובה Safari, לא כרום).
2. לחצו על כפתור השיתוף ⬆️ בתחתית המסך.
3. גללו ובחרו **"הוסף למסך הבית" (Add to Home Screen)**.
4. לחצו "הוסף" - האייקון יופיע במסך הבית כמו אפליקציה רגילה.

כל מכשיר (אייפון) שרוצים שהאפליקציה תעבוד עליו צריך לבצע את השלבים האלה בעצמו, פעם אחת, כשיש אינטרנט. אחרי ההתקנה הראשונה האפליקציה עובדת גם בלי אינטרנט/בטיסה/במקומות מרוחקים בפרו.

## עדכון המסלול

כל התוכן נמצא במערך `itinerary` בתוך `index.html`. אחרי כל שינוי:
1. עדכנו את `sw.js` והעלו את `CACHE_VERSION` (למשל מ-`peru2026-v1` ל-`peru2026-v2`) - זה מה שגורם למכשירים להוריד את הגרסה המעודכנת.
2. עשו `git push` לריפו.
3. במכשירים שכבר התקינו את האפליקציה, לפתוח אותה כשיש אינטרנט כדי שתתעדכן ברקע (העדכון ייכנס לתוקף בפתיחה הבאה).

## מבנה הפרויקט

- `index.html` - האפליקציה עצמה (HTML+CSS+JS, קובץ אחד)
- `manifest.webmanifest` - הגדרות ה-PWA (שם, אייקונים, צבעים)
- `sw.js` - Service Worker לתמיכה באופליין
- `icons/` - אייקונים בגדלים שונים
